1. 프로젝트 소개

만든 이유
CRISPR 유전자 가위는 질병 치료와 생명공학 분야에서 주목받는 기술이지만, 학생들에게는 개념이 어렵고 "편집할 위치를 실제로 어떻게 정하는지" 직접 접해 볼 기회가 거의 없습니다. 이 프로젝트는 gRNA(가이드 RNA) 후보를 찾고 평가하는 과정과 유전자 편집의 실제 순서를 웹에서 직접 체험하며 이해할 수 있도록 만들었습니다.

목표
- NCBI 데이터베이스의 실제 유전자 서열에서 SpCas9 표적(20 nt + NGG PAM)을 찾아 gRNA 후보로 제시한다.
- 후보를 안전성과 효율성 점수로 평가해 임상 적합성을 스크리닝하는 도구를 구현한다.
- 중학생 등 학생들이 게임이 아닌 실제 유전자 편집 과정에 가까운 실습을 할 수 있게 한다.

사용 기술
- 언어, 프레임워크: Python, Streamlit
- 데이터: NCBI E-utilities(efetch)로 가져온 RefSeq 전사체(mRNA) 서열
- 분석, 시각화: pandas, Plotly(2D 맵), Matplotlib, ReportLab(PDF)
- 통신: Python requests
- 배포: GitHub(저장소: CRISPR), Streamlit Community Cloud

2. 사용법

1페이지: gRNA 스크리닝
사이드바에서 설정하면 결과가 자동으로 갱신됩니다. (별도의 실행 버튼은 없습니다.)

1. 가중치 비율: 안전성(MIT)과 효율성(Doench) 가중치 슬라이더로 두 점수의 비율을 정합니다. 한쪽을 움직이면 다른 쪽은 합이 100%가 되도록 자동으로 바뀝니다.
2. 최소 품질 컷오프: 최소 요구 안전성 점수를 정합니다. 이 점수보다 낮은 후보는 제외됩니다.
3. 표적 서열: 입력 방식을 고릅니다.
   - NCBI 실제 서열로 설계
     - 유전자 선택 메뉴에서 HBB, BRCA1, TP53, CFTR, PCSK9 중 하나를 고르거나, 메뉴 맨 아래 "직접 입력"을 골라 RefSeq 전사체 번호(예: NM_000518)를 직접 넣습니다.
     - "탐색 구간" 슬라이더로 찾을 범위를, "표시할 후보 수" 슬라이더로 보여 줄 후보 수를 정합니다.
   - 예시 데이터
     - 미리 준비된 후보 목록(HBB, BRCA1, TP53 중 하나)이 입력창에 채워져 있습니다.
     - "다른 예시 데이터 불러오기" 버튼을 누르면 다른 유전자의 목록으로 바뀝니다.
     - ﻿   - 입력창을 직접 고쳐 쓸 수도 있습니다. 한 줄에 후보명, 20글자 서열 형식으로 적습니다.
4. 결과 화면에서 다음을 확인합니다.
   - 표시 후보 수, 최상위 후보, 최고 종합점수, 평균 안전성
   - TOP CANDIDATE 카드(최상위 후보의 서열, GC 함량, 안전성·효율성·종합 점수)
   - 2D 스크리닝 맵 탭: 가로축 효율성, 세로축 안전성이고, 점의 크기와 색이 종합 점수입니다.
   - 상세 결과 데이터 탭: 전체 후보 표와 CSV 다운로드 버튼
5. PDF 요약 리포트 생성 버튼을 누른 뒤 PDF 리포트 다운로드 버튼으로 결과를 저장합니다.
6. 이 gRNA 후보로 유전자 편집 실습 시작하기 버튼을 누르면 최상위 후보로 2페이지가 열립니다.

형식이 틀린 줄(쉼표 없음, 20글자가 아님, A/C/G/T 이외의 글자)은 분석에서 제외되고, 제외된 줄과 이유가 경고로 표시됩니다.

2페이지: 유전자 편집 실습실
1. 1페이지에서 최상위 후보가 정해진 뒤 "실습 시작하기" 버튼 또는 사이드바의 "실습실" 메뉴로 들어옵니다.
2. 화면 위에는 선택한 표적 유전자, gRNA 서열, 점수, 서열 출처가 표시됩니다.
3. 실습은 7단계입니다: ① 표적 찾기 → ② RNP 만들기 → ③ 세포 안으로 전달 → ④ 표적 결합 → ⑤ DNA 절단 → ⑥ 세포의 수리 → ⑦ 결과 확인
4. 단계마다 이 단계 설명 보기, 전체 과정 한눈에 보기 버튼으로 실제 유전자 편집 과정의 설명글을 열어 볼 수 있습니다. 막히면 힌트 버튼을 누릅니다.
5. 1단계에서는 DNA에서 gRNA와 똑같은 20글자 구간을 찾아 그 구간의 글자를 클릭합니다.

3페이지: 용어 사전
사이드바의 "용어사전" 메뉴로 들어옵니다. 실습 중 낯선 말이 나오면 언제든 열어 볼 수 있습니다.
용어 검색칸에 단어(예: PAM, 시퀀싱, 오프타깃)를 입력하면 용어 이름이나 설명에 그 단어가 들어 있는 용어만 보여 줍니다.
분류버튼으로 전체 또는 아래 5개 분류 중 하나를 골라 볼 수 있습니다.
DNA와 유전자 / CRISPR 도구 / 세포 안에서 일어나는 일 / 세포에 넣기와 확인하기 / 점수와 데이터
화면 위에 현재 보이는 용어 개수가 표시되고, 용어마다 이름, 분류, 쉬운 설명이 카드로 나옵니다. 검색 결과가 없으면 안내 문구가 나옵니다.


3. 주요 기능 설명

① NCBI 실제 서열 연동
﻿- ncbi_utils.py가 NCBI E-utilities의 efetch에 requests로 요청을 보내 RefSeq 전사체(mRNA) 서열을 가져옵니다.
- 기본 제공 유전자 5개(HBB, BRCA1, TP53, CFTR, PCSK9)는 실제 RefSeq 번호로 등록되어 있습니다. 예: TP53 → NM_000546
- 안전장치: 전사체 번호(NM_, NR_, XM_, XR_)만 허용해 염색체 전체처럼 아주 큰 서열을 실수로 받지 않게 했고, 30만 염기를 넘는 서열이나 A/C/G/T 이외의 글자가 있는 서열은 오류로 처리합니다.
- 같은 번호는 하루 동안 저장해 두었다가 다시 쓰므로 NCBI에 반복해서 요청하지 않습니다.
- 서열을 가져오지 못하면 앱이 멈추지 않고 오류 내용을 화면에 보여 줍니다.

② SpCas9 표적(gRNA 후보) 탐색
- 서열의 두 가닥(+, −) 모두에서 NGG PAM 앞의 20 nt를 후보로 찾습니다.
- 반대 가닥에서 찾은 표적은 뒤집어서, 표적과 PAM이 항상 위쪽 가닥에 오도록 맞춥니다.
- TTTT가 들어 있는 표적은 gRNA 발현에 불리하므로 제외합니다.
- 실습 화면에서 쓰도록 표적 앞 8 nt와 PAM 뒤 6 nt의 실제 서열도 함께 가져옵니다.

③ 임상 적합성 스크리닝
- 후보마다 GC 함량을 바탕으로 두 점수를 계산합니다.
  - 효율성(Doench): 표적 전체의 GC 함량이 50%에 가까울수록 높습니다.
  - 안전성(MIT): PAM에 가까운 뒤쪽 10글자(seed 영역)의 GC 비율이 50%에 가까울수록 높습니다.
- 종합 점수 = 안전성 × 안전성 가중치 + 효율성 × 효율성 가중치 (가중치는 슬라이더로 조절)
- 안전성이 컷오프보다 낮은 후보는 제외하고, 종합 점수가 높은 순으로 보여 줍니다.
- ⚠️ 이 점수는 교육용 간이 계산이며, 실제 MIT·Doench 알고리즘의 결과가 아닙니다.

④ 두 가지 입력 모드
- NCBI 실제 서열로 설계: 실제 유전자 서열에서 표적을 찾습니다. 인터넷 연결이 필요합니다.
- 예시 데이터: 미리 준비된 후보를 바로 체험하고, 직접 고쳐 쓸 수도 있습니다. 실제 게놈 서열과 대조하지 않은 연습용 데이터이며, 실습실의 주변 DNA는 설명을 위한 가상 서열로 표시됩니다.
- NCBI 연결이 어려울 때는 예시 데이터로 대체할 수 있습니다.

⑤ 결과 시각화와 저장
- 2D 스크리닝 맵으로 후보를 한눈에 비교합니다.
- 상세 결과 표를 CSV로 내려받을 수 있습니다.
- PDF 요약 리포트에는 생성 일시(한국 시간), 대상 유전자, 서열 출처, 가중치와 컷오프 설정값, 표시한 후보 수, 최상위 후보, 2D 맵 그림, 후보 순위 표가 들어갑니다.
﻿⑥ 유전자 편집 실습실
- 게임이 아니라 실제 유전자 편집 순서(7단계)를 따라가는 실습입니다.
- 세포 밖, 세포막, 세포질, 세포핵 구조 위에서 gRNA와 Cas9가 표적 DNA를 찾아가는 모습을 그림으로 보여 줍니다.
- NCBI 모드에서는 화면의 DNA 글자가 모두 실제 염기서열입니다.
- 단계별 설명글을 버튼으로 열어 볼 수 있어 학생이 스스로 학습할 수 있습니다.
